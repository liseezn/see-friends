专为 WordPress 打造的智能化全流程友情链接管理插件 ，基于原生链接体系深度扩展，无冗余臃肿代码，轻量高性能。 完整覆盖：前端申请、后台审核、智能反链检测、定时监控、邮件通知、用户自助修改、RSS订阅抓取、友链文章聚合、数据导入导出一站式管理。

## ✨ 插件简介
- 基于 WordPress 原生链接管理器底层开发，兼容原生所有接口，迁移无压力
- 超强穿透式智能反链检测：主页、页脚、导航、折叠菜单、友人帐、子页面、图片友链全覆盖
- 全可视化后台配置面板，所有功能一键开关，无需修改源码
- 申请审核、自动上下架、过期清理、批量检测、掉链告警、自助修改全自动运行
- 完美自适应浅色/深色主题，CSS 原生变量适配，卡片美观整洁
- 完全开源免费、持续维护更新，欢迎提交 Issue、Bug 反馈与 PR 贡献

## 🚀 核心功能
### 1. 智能反链检测（核心模块）
- 全场景检测：首页、页脚、导航栏、隐藏模块、友人帐、独立友链页、图片锚点友链
- 后台自定义反链关键词，中英文通用识别
- 自动扫描 `/friend` `/link` `/links` 等常见友链路径
- 支持单条检测、批量全站检测、每日定时自动检测，检测记录永久保存
- 内置防拦截 UA、超时容错、请求重试机制，稳定兼容各类防护站点

### 2. 一体化后台管理面板
- 独立配置页挂载于 WordPress「链接」菜单下
- 分栏清晰：基础设置、反链检测、邮件通知、RSS设置、前端展示、数据管理
- 内置站点数据总览统计卡片：总友链数、待审核、已通过、分类数量、插件版本一目了然
- 所有功能可视化开关，参数自定义，零代码使用
- 新增插件后台一键自动更新功能，无需手动下载上传安装包升级

### 3. 友链申请与自动审核
- 前端自助申请表单短代码，访客自由提交友链互换
- 后台一键审核：通过、拒绝、反链复检，自动同步原生链接上下架
- 智能自动通过：可自定义等待天数，满足时长+反链正常自动上线
- 全程邮件通知：申请人审核通知、管理员新申请提醒
- 独立 `link_apply` 友情链接申请表，完整留存申请人邮箱、审核状态、备注等元数据

### 4. 用户自助修改信息
- 独立修改表单短代码，站长无需手动修改信息
- 身份验证：网站地址 + 绑定邮箱双重校验
- 内置邮箱验证码防护，防止恶意篡改、恶意提交
- 支持修改：站点名称、链接、图标、简介、RSS 地址
- 修改提交后自动通知管理员审核，全程留痕可查

### 5. 数据备份与迁移管理
- CSV 完整导入 & 导出，支持全量友链备份、批量迁移
- 完整字段导出：链接名称、网址、图片、邮箱、描述、分类、备注等全部信息
- 支持按分类导出，数据备份更灵活
- 原生存量链接一键同步插件，自动去重不重复创建
- 自定义过期清理：自动删除长期未审核、已拒绝无效申请
- 危险操作二次确认，回收站防护，防止误删数据

### 6. 全链路邮件通知系统
- 申请通过 / 拒绝 → 邮件通知申请人
- 用户提交新申请、修改申请 → 邮件通知站长
- 友链掉链失效 → 定时告警提醒，支持重复提醒间隔限制
- 新增邮件通知模板自定义功能，所有系统邮件文案均可自由修改，无需改动插件源码

### 7. RSS 订阅与文章聚合
- 支持填写站点 RSS 订阅地址
- 友链卡片 RSS 图标固定右上角展示，可后台总开关控制
- 内置 RSS 定时自动更新，可自定义更新频率
- 新增友链文章聚合短代码，展示全网友链最新文章，按时间排序

### 8. 美观自适应前端展示
- 响应式网格友链卡片，电脑、手机完美适配
- 站点描述支持自动多行换行，后台可开关，长简介优雅展示
- 自定义图标大小、展示开关、链接打开方式、排序规则
- 原生深色模式适配，无样式错乱，对比度舒适

## 📋 环境要求
- WordPress 5.6 及以上 （兼容至 6.6+）
- PHP 7.0 及以上 （兼容至 8.3）
- 服务器未禁用 `wp_remote_get` 远程请求函数

## 📦 安装方法
### GitHub 直接安装
1. 前往项目 Releases 下载最新版 `see-friends.zip`
   https://github.com/liseezn/see-friends/releases
2. WordPress 后台 → 插件 → 安装插件 → 上传插件
3. 上传压缩包并启用插件即可
4. 插件自动初始化配置、注册定时任务，无需额外设置

### 自动更新（推荐）
已安装插件的用户，可直接在 WordPress 后台「插件」页面点击「更新」一键升级至最新版本。

### 旧版本异常修复升级步骤（必看）
针对旧版本设置无法保存的问题，请严格按照以下流程操作即可彻底修复：
1. 后台安装并激活本次 3.4.1 版本插件
2. 核对站点内所有友情链接、申请记录数据完整正常
3. 在 WordPress 后台卸载本插件（核心链接数据不会丢失）
4. 重新安装并激活插件，所有功能、设置保存均恢复正常
5. 后续新版本可直接使用插件内置自动更新功能一键升级，无需重复操作

## ⚡ 短代码
直接在页面/文章中插入即可使用 (或者使用基础短代码，后台设置一下)

| 短代码 | 功能说明 | 全部可用参数 |
|--------|----------|--------------|
| `[link_apply_form]` | 友链自助申请表单 | 无 |
| `[link_modify_form]` | 友链信息修改表单 | 无 |
| `[random_bookmarks]` | 随机展示友链列表 | `category=""` 指定友链分类ID<br>`limit="20"` 显示条数<br>`show_image="on/off"` 是否显示网站图标<br>`show_description="on/off"` 是否显示网站描述<br>`image_size="40"` 图标像素尺寸<br>`show_rss="on/off"` 是否显示右上角RSS图标<br>`target="_blank/_self"` 链接打开方式 |
| `[friend_rss_posts]` | 所有友链最新文章聚合展示 | `count="5"` 展示文章总数<br>`category=""` 指定单一友链分类筛选 |

## 📦 插件卸载数据留存规则
插件卸载时严格区分业务数据与配置数据，核心数据永久保留：

| 数据类型 | 卸载后状态 |
|----------|------------|
| 已添加的友情链接（含邮箱、图片等） | ✅ 保留 |
| link_apply 申请记录及元数据（邮箱、状态等） | ✅ 保留 |
| 插件全局设置（fabb_settings） | ❌ 删除 |
| 插件后台定时任务 | ❌ 清除 |
| 匿名统计 ID | ❌ 删除 |

## ❓ 常见问题 FAQ
- **批量检测网站卡顿？** 新版本内置超时限制、请求间隔、异常捕获，不会占用服务器资源，可放心使用。
- **对方已加友链但检测不到？** 开启后台图片检测、友链路径扫描，补充自定义关键词即可大幅提升识别率。
- **深色模式样式错乱？** 插件全局使用 CSS 变量自适应，已完全适配主流主题深色模式。
- **如何让友链站长自己修改友链？** 页面插入 `[link_modify_form]` ，用户凭网址+邮箱验证(可以关闭邮箱验证)即可提交修改。
- **旧站存量友链怎么批量导入？** 后台「数据管理」一键同步原生链接，或直接 CSV 批量导入。
- **表单不显示？** 检查后台对应功能总开关是否开启，再插入对应短代码即可。
- **旧版本设置无法保存怎么办？** 请按照上述"旧版本异常修复升级步骤"操作，即可彻底解决该问题。
