## 🚀 核心功能
### 1. 智能反链检测（核心模块）
- 全场景检测：首页、页脚、导航栏、隐藏模块、友人帐、独立友链页、图片锚点友链
- 后台自定义反链关键词，中英文通用识别
- 自动扫描 `/friend` `/link` `/links` 等常见友链路径
- 支持单条检测、批量全站检测、每日定时自动检测，检测记录永久保存
- 内置防拦截 UA、超时容错、请求重试机制，稳定兼容各类防护站点

### 2. 一体化后台管理面板
- 独立配置页挂载于 WordPress「链接」菜单下
- 分栏清晰：基础设置、反链检测、邮件通知、RSS设置、前端展示、数据管理
- 内置**站点数据总览统计卡片**：总友链数、待审核、已通过、分类数量一目了然
- 所有功能可视化开关，参数自定义，零代码使用

### 3. 友链申请与自动审核
- 前端自助申请表单短代码，访客自由提交友链互换
- 后台一键审核：通过、拒绝、反链复检，自动同步原生链接上下架
- **智能自动通过**：可自定义等待天数，满足时长+反链正常自动上线
- 全程邮件通知：申请人审核通知、管理员新申请提醒

### 4. 用户自助修改信息
- 独立修改表单短代码，站长无需手动修改信息
- 身份验证：网站地址 + 绑定邮箱双重校验
- 内置**邮箱验证码防护**，防止恶意篡改、恶意提交
- 支持修改：站点名称、链接、图标、简介、RSS 地址
- 修改提交后自动通知管理员审核，全程留痕可查

### 5. 数据备份与迁移管理
- **CSV 完整导入 & 导出**，支持全量友链备份、批量迁移
- 原生存量链接一键同步插件，自动去重不重复创建
- 自定义过期清理：自动删除长期未审核、已拒绝无效申请
- 危险操作二次确认，回收站防护，防止误删数据

### 6. 全链路邮件通知系统
- 申请通过 / 拒绝 → 邮件通知申请人
- 用户提交新申请、修改申请 → 邮件通知站长
- 友链掉链失效 → 定时告警提醒，支持重复提醒间隔限制

### 7. RSS 订阅与文章聚合
- 支持填写站点 RSS 订阅地址
- 友链卡片 **RSS 图标固定右上角展示**，可后台总开关控制
- 内置 **RSS 定时自动更新**，可自定义更新频率
- 新增友链文章聚合短代码，展示全网友链最新文章，按时间排序

### 8. 美观自适应前端展示
- 响应式网格友链卡片，电脑、手机完美适配
- 站点描述支持**自动多行换行**，后台可开关，长简介优雅展示
- 自定义图标大小、展示开关、链接打开方式、排序规则
- 原生深色模式适配，无样式错乱，对比度舒适

## 📦 安装方法
### GitHub 直接安装
1. 前往项目 **Releases** 下载最新版 `see-friends.zip`
   > https://github.com/liseezn/see-friends/releases
2. WordPress 后台 → 插件 → 安装插件 → 上传插件
3. 上传压缩包并启用插件即可
4. 插件自动初始化配置、注册定时任务，无需额外设置

## ⚡ 短代码
直接在页面/文章中插入即可使用
(或者使用基础短代码，后台设置一下)
| 短代码 | 功能说明 | 全部可用参数 |
|--------|----------|--------------|
| `[link_apply_form]` | 友链自助申请表单 | 无 |
| `[link_modify_form]` | 友链信息修改表单 | 无 |
| `[random_bookmarks]` | 随机展示友链列表 | `category=""` 指定友链分类ID<br>`limit="20"` 显示条数<br>`show_image="on/off"` 是否显示网站图标<br>`show_description="on/off"` 是否显示网站描述<br>`image_size="40"` 图标像素尺寸<br>`show_rss="on/off"` 是否显示右上角RSS图标<br>`target="_blank/_self"` 链接打开方式 |
| `[friend_rss_posts]` | 所有友链最新文章聚合展示 | `count="5"` 展示文章总数<br>`category=""` 指定单一友链分类筛选 |

## ❓ 常见问题 FAQ
1. **批量检测网站卡顿？**
   新版本内置超时限制、请求间隔、异常捕获，不会占用服务器资源，可放心使用。

2. **对方已加友链但检测不到？**
   开启后台图片检测、友链路径扫描，补充自定义关键词即可大幅提升识别率。

3. **深色模式样式错乱？**
   插件全局使用 CSS 变量自适应，已完全适配主流主题深色模式。

4. **如何让友链站长自己修改友链？**
   页面插入 `[link_modify_form]`，用户凭网址+邮箱验证即可提交修改。

5. **旧站存量友链怎么批量导入？**
   后台「数据管理」一键同步原生链接，或直接 CSV 批量导入。

6. **表单不显示？**
   检查后台对应功能总开关是否开启，再插入对应短代码即可。
